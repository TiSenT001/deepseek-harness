# 对标 Obsidian：差距清单与执行方案

> 依据：Obsidian 官方帮助（[Graph view](https://obsidian.md/help/plugins/graph-view)、[File explorer](https://obsidian.md/help/plugins/file-explorer)），以及在本机 vault（559 篇）上的实测对比。
> 本文只写「显示逻辑」和可见行为，不讨论编辑能力。

---

## 一、结论先说

我们目前实现的是「Obsidian 阅读视图的功能子集」，差距集中在三类：

1. **图谱的显示规则是简化版**：节点大小、默认过滤、分组、显示参数、力参数都缺。
2. **文件列表与标签页是只读骨架**：没有排序、右键菜单、拖拽、每标签历史。
3. **阅读视图的细节没对齐**：反链不折叠、块引用不支持、属性不可交互。

下面逐条列，然后给分阶段方案。

---

## 二、图谱：显示逻辑对照

| # | Obsidian 规则 | 我们当前 | 差距 | 计划 |
|---|---|---|---|---|
| G1 | 节点半径由**入链数**决定（"The more notes that link to a given note, the larger its circle"） | 用无向度数（入+出） | 出链多的枢纽被放大 | ✅ 本轮已改为入链 |
| G2 | 悬停高亮该笔记的**全部连接** | 高亮悬停节点 + 邻居，其余淡出 22% | 基本一致，邻居标签未强制显示 | ✅ 本轮已让邻居标签始终显示 |
| G3 | 点击打开笔记；**右键**出动作菜单（新标签打开、复制链接等） | 只有左键打开 | 缺右键菜单 | P1 |
| G4 | 缩放：滚轮或 `+`/`-`；平移：拖拽或方向键（Shift 加速） | 滚轮 + 拖拽 | 缺键盘 | P1 |
| G5 | Filters：**Search files**（支持搜索算子）、**Tags**（标签作为节点）、**Attachments**（附件节点）、**Existing files only**（隐藏未解析）、**Orphans** | 只有文本、标签、跳数、隐藏孤立 | 缺「标签节点 / 附件节点 / 仅存在文件」和搜索算子 | P1（Host + UI） |
| G6 | Groups：按查询给节点**分组着色**，可多组 | 无 | 缺 | P1 |
| G7 | Display：**Arrows**（方向箭头）、**Text fade threshold**（标签淡出阈值）、**Node size**、**Link thickness**、**Animate**（时间流逝动画） | 都没有；尺寸写死 | 缺整套显示参数 | P1 |
| G8 | Forces：**Center force / Repel force / Link force / Link distance** | 常量写死在 layout.ts | 缺可调 | P1（低频，可后置） |
| G9 | 默认就显示**未解析链接**（幽灵节点），勾选 "Existing files only" 才隐藏 | 完全不出未解析节点 | 缺 | P1（Host 出 unresolved 节点） |
| G10 | 局部图默认深度可配；全局图在独立面板 | 深度 1/2/3 下拉 | 基本一致 | — |

### 本轮已修的两条

- **G1**：`src/client/graph/layout.ts` 的 `simulate()` 改为按 `edge.target` 计数（入链），半径 `3.2 + sqrt(inbound) * 1.4`。
- **G2**：`GraphView` 的 `labelVisible()` 对悬停邻居也返回 true，邻居名字不会因避让被隐藏。

## 六、执行方案（按优先级）

> 每阶段结束都跑：`tsc --noEmit` + `node --test tests/*.test.ts` + Playwright 冒烟；改到 Host 的阶段需要重启一次宿主。

### P0 — 显示规则修正（本轮已完成）
- [x] 节点大小按入链数
- [x] 悬停时邻居标签常显
- 验收：同一张图里，被引用最多的笔记最大；悬停任意节点，邻居名字可见。

### P1 — 图谱设置面板（✅ 已完成）
目标：把 Obsidian「齿轮」里的四组设置搬进来。
- [x] **Filters**：搜索（`file:` / `path:` / `tag:` 算子，Host 过滤）、标签节点、附件节点、仅存在文件、孤立节点
- [x] **Groups**：新增/删除分组（查询 + 颜色），节点按首个匹配组着色
- [x] **Display**：箭头、文字淡出阈值、节点大小倍率、连线粗细
- [x] **Forces**：中心力、斥力、连线力、连线距离
- [x] **Host**：`/graph` 支持 `unresolved` / `attachments` / `tags` 开关，节点带 `kind` 与 `tags`
- [x] 设置持久化到 localStorage（`dsh.obsidian.graph.settings`），schema 驱动渲染
- 实测：默认中心图 214 节点含 **31 个幽灵节点**；勾选「仅存在文件」后 179 节点、幽灵归零；「标签作为节点」63 节点含 13 个标签节点；箭头开启后 338 条连线带 marker；节点大小滑杆 1→1.8 时半径 6.6→11.9。

### P2 — 文件列表（✅ 已完成，拖拽移动除外）
- [x] 排序切换（名称 / 修改时间）、显示扩展名、全部折叠
- [x] 右键菜单：打开 / 在新标签页打开 / 复制路径 / 重命名 / 删除
- [x] 新建笔记、新建文件夹（工具栏 + 目录右键）
- [x] **Host**：`/tree` 带 `mtime`/`size`；新增 `rename` / `delete` / `mkdir`，全部经 `VaultFiles` 做根内校验
- [x] 删除默认**移到 `.trash`**（Obsidian 默认行为），不是物理删除
- [ ] 拖拽移动（Obsidian 会自动重写链接；我们至少保证移动后仍能解析，留待下一步）
- 实测：`mkdir → create → rename → delete` 全部 200；删除后树中无残留，`.trash` 内出现 `<时间戳>-<名字>`；改名后索引重建。
- 已知限制：`ctx.fs` 服务不提供 rename/remove/mkdir/mtime，也没有写工作区外文件的权限，因此这些操作走 Node fs 并做根内路径校验（`VaultPathError` 拒绝 `../` 与绝对路径）。

### P3 — 标签页（✅ 已完成）
- [x] 预览标签：单击文件为斜体预览，再点另一个文件复用同一个标签（实测标签名 README → TiSenT OS，标签数仍为 1）
- [x] 双击标签 / 右键「固定」把它变成正式标签
- [x] 每标签独立 history：`Alt+←` 在该标签内回退（实测 外部大脑 → 个人知识库 → 回退到 外部大脑）
- [x] 每标签独立滚动位置：实测切走再切回 `scrollTop` 900 → 900（早期实现会被首帧短文档夹到 0，已改为多帧重放 + 恢复期间忽略 scroll 事件）
- [x] 右键菜单：关闭 / 关闭其他 / 关闭全部 / 固定
- [x] `+` 新标签、中键关闭；快速切换与链接打开为正式标签（替换当前标签，等同 Obsidian）
- 验收：两个标签来回切换，各自回到原滚动位置；关闭其他后只剩当前。

### P4 — 阅读视图（✅ 已完成）
- [x] 反链按来源分组：组头显示来源与提及数，默认展开 2 条上下文，可「展开 / 收起」；未链接提及同样按来源分组
- [x] 块引用 `^id`：Host 扫 `^block-id` 建索引（`NoteDto.blocks`），阅读视图把 `^id` 渲染成 `data-block-id` 并隐藏标记；`[[note#^id]]` 跳转并**高亮闪烁** 1.6s
- [x] 嵌入精确到小节 / 段落：`![[note#Heading]]` 只取该标题到下一个同级标题；`![[note#^id]]` 只取该段落
- [ ] 属性交互（复制值）—— 留到 P5 一起做
- 实测：section 嵌入不含 `第三节内容`；block 嵌入只含 `第一段内容`；块跳转后 `data-block-id="blk1"` 命中、`^blk1` 文本已剥离、`animation: ov-flash`；反链 21 组，来源 `source` 计 3 条。

### P5 — 打磨（✅ 已完成）
- [x] 加载骨架：笔记请求期间显示 6 行脉冲占位（实测 1 个骨架 / 6 行）
- [x] 图键盘操作：`+`/`-` 缩放（实测 scale 1 → 1.208）、方向键平移（Shift 加速，实测 translate 340 → 244）
- [x] 窄屏：≤1080px 时笔记树与右栏变为抽屉，顶栏出现「笔记树 / 大纲」切换按钮；实测 980px 下抽屉入场/出场正常、`scrollWidth === clientWidth`（无横向滚动）
- [x] 属性值点击复制，行内显示「已复制」反馈（实测 `created · 已复制`）
- [x] 主题 token 审计：客户端除 `theme.ts` 外只有一处十六进制色（分组预设色板 `GROUP_COLORS`，属于用户可选的**数据**而非主题色）
