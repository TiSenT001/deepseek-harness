## 一、整体结构

```
{{VAULT_NAME}}/
├── 知识库总览/                  ← 全局规范 + 索引
│   ├── {{VAULT_NAME}}.md        ← 主控 MOC
│   ├── 笔记编写规范.md          ← 本文件
│   ├── kb-conventions.md        ← 速查
│   ├── 关键词快速检索.md        ← 全局关键词索引
│   └── 仪表盘.md                ← Dataview 自动聚合
├── TA技术美术/                  ← CG/渲染/材质
├── 工具链/                      ← CG 管线工具
├── 外部大脑/                    ← 知识管理 / 外部系统
├── 项目/                        ← 实际项目
├── 美学/                        ← 视觉美学
├── 游戏设计/                    ← 关卡/理论
├── 哲学/                        ← 认知/存在/美学
├── 收件箱/                      ← 外部工具输出（待归档）
├── Pur画布/                     ← Pur Studio 画布
└── 附件/                        ← 图片等附件（扁平存储）
```

## 二、层级定义

| 层级 | 文件 | 作用 |
|------|------|------|
| 主控 MOC | `{{VAULT_NAME}}.md` | 全库首页，列出所有分类入口 |
| 领域 MOC | `<领域名>.md` | 完整目录 + 关键关联 |
| 子目录 | 按主题分组 | 笔记超过 5 篇时再分文件夹 |
| 笔记 | `<引擎前缀> <中文主题>.md` | 具体笔记 |

## 三、Frontmatter 规范

```yaml
---
tags: [标签1, 标签2]        # 必填
created: YYYY-MM-DD          # 必填
domain: 领域名               # 必填 — TA技术美术/工具链/外部大脑/项目/美学/游戏设计/哲学
type: reference|spec|moc     # 必填
engine: UE|Unity|C4D         # TA/工具链笔记必填
topic: 主题                  # 可选
updated: YYYY-MM-DD          # 重大修改时更新
---
```

## 四、正文格式

```
领域标签 主题标签 参考
> 📎 索引：**领域MOC** · 关系词 → 最强关联笔记

# 标题

正文内容
```

- 正文第一行：wikilink 标签行
- 第二行：📎 索引行 —— 领域 MOC + 1 个最强关联
- 笔记之间通过 wikilink 互链，不靠文件夹层级表达关系

## 五、文件命名

- 格式：`<引擎前缀> <中文主题>.md`
- 示例：`UE 视差纹理实现指南.md`、`[B站] UE5 材质大师课.md`
- 项目笔记：`<项目名> <主题>.md`
- 禁止：纯英文（专有名词除外）、特殊字符、过于简短
- 标题必须与 wikilink 引用逐字一致（空格、标点、后缀）
- 禁止「（精简版）」「（最终版）」等后缀，wikilink 不会带后缀

## 六、领域清单

| 领域 | 目录 | MOC | 子目录规则 |
|------|------|-----|-----------|
| TA技术美术 | `TA技术美术/` | `TA技术美术.md` | 按引擎→主题两层 |

| 哲学 | `哲学/` | `哲学.md` | 按主题 |

### 跨领域链接

**只链子目录笔记，不链 MOC 一级目录。** 索引行 `📎 领域MOC` 是唯一例外；同域内链 MOC 不受此限。

## 七、标签分类

- **主题聚合标签**：需要创建同名 `.md` 占位文件（`type: search-index`），例如材质、渲染、VFX
- **辅助标签**：只写进 frontmatter，不建文件，例如 B站、论文、规范、Obsidian
- 统一用词，不造同义词；新增主题标签时同步创建占位笔记

## 八、图片与附件

- 统一放在 `附件/` 扁平目录
- PNG 大于 200KB 转 JPEG q88；JPEG 统一 q80
- 嵌入写成 `!附件/<图片名>`
- 收藏图放在 `收藏/<来源>/`，不嵌入笔记

## 九、外部工具输出

Trae 等外部 AI 工具的输出先进 `收件箱/`，不要直接写知识库根目录；定期转换、归档并更新 MOC。

## 十、Git 提交前缀

- `add:` 新增 · `update:` 修订 · `refactor:` 重构 · `fix:` 修正 · `feat:` 新功能 · `style:` 样式/配色

## 十一、创建笔记前检查清单

```
□ 1. 文件命名：<引擎前缀> <中文主题>.md ？特殊字符？
□ 2. 目录位置：属于哪个领域？哪个子目录？
□ 3. 目标标题：wikilink 引用的目标标题是否已存在？
     → 主题聚合标签需有对应 .md 占位文件
□ 4. Frontmatter：tags 用已有词汇表？domain/type/engine 填了？
□ 5. 标题无多余后缀
□ 6. 索引行：📎 指向领域MOC + 1 个最强关联
□ 7. 跨域链接：只链子目录笔记，不链 MOC 一级目录
□ 8. 已更新领域 MOC 与关键词检索
```

## 十二、Pur Studio 画布

- 扩展名 `.PurStudio`（JSON：`{elements, viewState}`）
- 位置 `Pur画布/`，按类别建子目录
- 节点库只放节点定义，不加连线；连线演示另存一份
- 修改前先关 Obsidian，避免自动保存覆盖
