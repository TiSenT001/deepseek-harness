# dsh-obsidian-vault

DeepSeek Harness 的 Obsidian 风格知识库工作区：以**独立插件**形式加载，不改 DSH 与 `dsh-better-sidebar` 的任何源码。

左侧栏出现「知识库」入口，主栏是 Obsidian 式的三栏工作区：笔记树 / 阅读视图 / 大纲·反链·属性·标签；支持 `[[双链]]`、`[[笔记#标题]]`、`![[嵌入]]`、别名解析、快速切换（`Ctrl+O`）、全文搜索和局部/全库关系图。

## 安装

```sh
dsh plugin --profile <profile> add /path/to/plugins/dsh-obsidian-vault
```

或让 DSH 安装本地包目录（`plugin_manager install_bundle`）。安装后**重启 DSH**（Host 侧路由需要重启生效），页面刷新即可看到左侧栏入口。

### 配置（`cordis.patch.yml`）

```yaml
- insert:
    - id: obsidian-vault
      name: dsh-obsidian-vault
      config:
        vault: 'G:\个人知识库'
```

| 字段 | 默认 | 说明 |
|---|---|---|
| `vault` | 最近的 `.obsidian` 祖先目录，否则进程工作目录 | 知识库根目录 |
| `ignore` | `.obsidian` `.trash` `.git` `node_modules` `.DS_Store` `__pycache__` | 跳过的目录名；点开头的名字一律忽略（与 Obsidian 一致） |
| `maxFileBytes` | 2 MiB | 超过此大小的笔记只索引元数据 |
| `maxIndexBytes` | 64 MiB | 正文常驻内存的总预算；超出后按需读取 |
| `maxDepth` | 12 | 目录遍历深度上限 |

## Pur Studio 画布

画布是一个独立页面：左侧栏「打开 Pur Studio」新建一个 `.purstudio` 文件，或直接在文件树里打开已有画布。文档本身是 JSON，写在知识库里，随笔记一起备份。

| 操作 | 行为 |
|---|---|
| 拖动空白 | 平移 |
| 滚轮 | 以指针为锚点缩放（5%–1000%） |
| 单击 / 框选 / `Ctrl`+单击 | 选择、框选、追加选择 |
| 拖动卡片 | 移动；靠近其他元素时 8px 吸附并显示参考线，`Alt` 临时关闭 |
| 拖到画布边缘 | 自动平移，速度随进入深度增长 |
| 8 个手柄 | 缩放卡片（图片保持比例，文本自由）；拖动边缘同样吸附 |
| 双击空白 / 卡片 / 群组 / 图片 | 新建文本 / 编辑 / 编辑群组 / 预览或打开链接 |
| 单击连线 / 双击连线 | 选中连线（Delete 删除）/ 编辑线条样式与箭头 |
| 右键连线 → 取消连接 | 断开两端但保留线条形状，可继续拖动、删除 |
| 点击连线 | 沿绘制路径命中（贝塞尔弧线任意位置都能选中；卡片覆盖处优先选卡片） |
| 笔记链接卡 | 只显示笔记标题，正文与备注在编辑器里编辑；标题超长会截断，不会溢出卡片 |
| 从引脚拖到空白画布 | 松开后选择新建文本或代码节点，并自动连线 |
| 悬停 600ms | 提示双击会做什么，并按命中位置给出光标 |
| `Tab` / `Shift+Tab` | 遍历元素（含群组子元素），视口外的元素自动居中 |
| `Esc` | 取消进行中的拖动、框选或平移，否则清空选区 |
| 方向键 / `Shift`+方向键 | 微移 1 / 10 单位，连续按键合并为一次撤销 |
| `Ctrl+X` / `Ctrl+C` / `Ctrl+V` / `Ctrl+D` | 剪切 / 复制 / 粘贴 / 复制一份 |
| `Ctrl+G` / `Ctrl+Shift+G` | 成组 / 拆组 |
| `F` / `0` / `+` / `-` | 适应视图 / 100% / 放大 / 缩小 |
| `Ctrl+S` | 立即保存（修改也会自动保存） |
| 右键 | 画布菜单：新建、导入、保存/导出、适应视图、弹出独立窗口 |

### 导入 PureRef

「导入 ▸ 导入 PureRef 画布」把 `.pur` 放进当前画布；「导入 PureRef 画布为…」在旁边新建一个画布。支持三种容器：

| 容器 | 结果 |
|---|---|
| 原生 SQLite 版 `.pur` | 按原始坐标还原：位置、尺寸、旋转、镜像、层级、群组、备注文字与颜色/字号/固定尺寸、缩略图 |
| 旧版内嵌图片版 `.pur`（无 SQLite） | 扫描内嵌 JPEG/PNG，按网格近似排布，并提示「近似导入」 |
| qCompress 包裹的 `.purz` | 先解压，再按上面两种处理 |

导入后新卡片会被选中并自动框选到视口内；无法识别的容器会明确提示失败，而不是静默导入 0 个元素。

### 已知限制

- 手绘笔迹与动图/视频暂不导入（画布还没有对应的元素类型）。
- 触控双指缩放未实现；触控板的双指手势走浏览器的 `Ctrl+滚轮`，可用。
- 撤销只覆盖元素，不覆盖视口。


### 画布设置（面板）

「设置 → 插件」**点开 Pur Studio 卡片**，详情里就是该插件的**画布设置**；改完点「保存」，重开画布生效：

| 设置 | 默认 | 作用 |
|---|---|---|
| 运行超时 | 1500ms | 代码节点单次运行上限（200–10000） |
| 允许运行代码 | 开 | 关闭后宿主拒绝 `pur/run-code`（403），画布提示已关闭 |
| 自动保存延迟 | 400ms | 编辑后写盘防抖（100–5000） |
| 大画布提示阈值 | 4MB | 内联图片超过该体积时提示外部化 |
| 显示网格 | 开 | 新画布是否绘制网格 |
| 网格透明度 | 1 | 网格线透明度（0–1），只影响网格线 |
| 吸附对齐 | 开 | 拖动时吸附到相邻卡片的边缘与中心 |
| 吸附半径 | 8px | 0 关闭吸附（0–40） |
| 自动平移上限 | 12 | 拖到边缘时每帧最大平移量（1–60） |
| 连线命中容差 | 25px | 点选连线的容差（8–60） |
| 导出倍率 | 1× | 位图导出缩放（1–3） |
| PNG 透明背景 | 开 | 关闭则用画布底色填充 |
| JPG 质量 | 0.9 | 0.4–1 |

索引组（保存后重启 DSH 生效）：库根目录、排除目录（每行一个）、单篇索引上限、索引正文总量、遍历深度。

值存在插件自己的 `.data/settings.json`，字段级覆盖 `cordis.yml` 里的插件配置；同样的字段也能在 DSH 的插件配置里设默认值（插件导出了 Config schema，面板外也能改）。
### 运行节点

选中代码节点 → 右键「运行节点」：宿主用 `node:vm` 在独立上下文里执行 `function process(inputs)`，1.5 秒超时，输入取自连线另一端的输出值（未连接为 `null`）。结果写在输出引脚旁（`result = 0`），卡片底部显示 `✓ 1ms` 或 `✗ 原因`，并随文档持久化，可直接喂给下游节点。

- 「运行全部」按连线拓扑序依次运行，上游结果直接喂给下游；有环时报错不执行；
- 运行期间节点描蓝色虚线框，失败后描红框；
- 最近 5 次运行记录在节点里，编辑器「运行历史」可以一键载回某次输出；
- 编辑器里的「运行结果」可以手填输出值（留空清除），节点因此也能当常量用；
- 同一节点可反复运行，输出值覆盖旧值；
- 代码为空时不执行，只提示；
- 宿主路由新增后需要重启 DSH 才生效；
- Obsidian 适配器没有该路由，会提示「Run node needs the DSH pane」。

## 架构

```
Host（Node）                          Client（浏览器）
src/index.ts     插件入口/Config       src/client/index.tsx  注册左侧栏图标 + 主栏页面
src/routes.ts    /obsidian/api/*      src/client/api.ts     唯一的 fetch 层
src/vault/index.ts   索引与查询        src/client/ui/        页面、树、阅读、面板、图
src/vault/syntax.ts  语法扫描  ←共享→  src/client/markdown/rewrite.ts  [[..]] 改写
src/vault/resolver.ts 链接解析规则     src/client/primitives.ts 复用宿主 MarkdownText
src/vault/frontmatter.ts YAML 子集
src/vault/watch.ts   目录监听 + 去抖
```

- **语法只有一份实现**：`vault/syntax.ts` 同时服务 Host 索引与浏览器改写。
- **渲染不重写**：`[[..]]` 被改写成哨兵链接（`https://dsh-obsidian.invalid/open|new`），交给宿主共享的 `MarkdownText`（来自 `@deepseek-ai/dsh-client-ui-primitives`，属于 shell 模块表，不重复打包）。
- **不落盘状态**：客户端只持有导航历史；索引全部在 Host，按 `版本 + 大小` 失效，目录监听 250ms 去抖，内容无变化不递增版本。
- **模块边界**：画布（`src/pur-kernel` + `src/client/pur`）与笔记工作区相互独立，只通过内核 barrel 与 `client/pur/integration.ts` 打交道；共享视觉能力在 `client/ui/kit`。规则与校验见 [docs/BOUNDARIES.md](docs/BOUNDARIES.md)，`npm run check:boundaries` 会在违规时失败。

## 大画布压测

内联图片会让文档涨到几十上百 MB，加载与保存的成本都在这里。用固定尺寸的合成文档量一次，超预算即失败：

```sh
# 300 张 200KB 内联图（约 59MB），用完自动删除临时画布
npm run bench:large -- 'http://127.0.0.1:3080/?token=...'

# 自定义规模
node --experimental-strip-types scripts/pur-large-doc-bench.mjs '<url>' --elements 500 --image-kb 256
```

本机基线（59MB / 300 图）：读取 1587ms、解析 32ms、序列化 46ms、写回 523ms。

真实样本参考：117.8MB 画布（523 张内联图）打开约 3.2s、保存约 1.65s；执行「外部化画布图片」后文档降到 **127KB**、读取 **15ms**，图片改存到 `.data/images`（内容寻址）。所以遇到大画布优先外部化，压测用来盯住不回归。

三类回归基线都有人可执行的重录脚本；**布局或几何是有意改动时，重录并审阅 diff**，不要手改：

```sh
# 全部重录（控制器轨迹 + 菜单树 + 渲染调用 + 引脚几何）
npm run regen:expected

# 只重录某一类
node --experimental-strip-types scripts/regen-expected.mjs --suite controller
node --experimental-strip-types scripts/regen-expected.mjs --suite menu
node --experimental-strip-types scripts/regen-expected.mjs --suite render
node --experimental-strip-types scripts/regen-expected.mjs --suite geometry

# 只重录名字匹配的场景（其余原样保留）
node --experimental-strip-types scripts/regen-expected.mjs --suite controller --scenario pin-new-line
```

- 场景数据来自 `tests/helpers/pur-controller-expected.ts`，回放与断言共用 `tests/helpers/expected-harness.ts`，重录不会和测试逻辑分叉。
- 场景按「一个元素一行」的紧凑 JSON 写回（40 个控制器场景约 2.3k 行，而不是 36k），改一个字段只动一行，diff 可读。
- 重录后必须跑 `npm test`；如果某个场景的轨迹与旧基线不同，在提交信息里写明「有意偏离」的原因。

仍然不做的：

- **行内 Live Preview**：需要编辑器内核，属于另一个产品面；当前是「源码编辑 + 阅读视图」两态。
- **Obsidian 插件生态 / 主题市场**：设置里的「核心插件」开关只模拟 Obsidian 的布局开关，不会加载真实的 Obsidian 插件。
- **附件进树**：附件只用于 `![[嵌入]]`。
- **歧义链接选择器**：直接打开最短路径候选，用点状下划线提示。
- **移动端手势**：窄屏下抽屉化，不做双指缩放与长按菜单（画布双指缩放也在明确排除项里）。

### 图谱基准

```bash
npm run bench:graph                                  # 5000 节点 / 15000 边
npm run bench:graph -- --nodes 1000 --ticks 60       # 更小的图
npm run bench:graph -- --json                        # 机器可读
```

直接驱动力模拟，输出每 tick 耗时与堆增量，默认预算 80ms/tick。模拟按节点数自动降频（≤600 节点 60fps、≤1500 40fps、≤3000 25fps、更大 15fps），持续动画在 5000 节点下仍有约 15fps 的演算节奏。

### 大库基准

```bash
npm run bench:vault                                  # 2000 篇合成笔记
npm run bench:vault -- --notes 5000 --queries 60     # 更大规模
npm run bench:vault -- --json                        # 机器可读
```

脚本在临时目录生成 N 篇合成笔记（文本、frontmatter、标签、双链、围栏代码），用宿主的 `VaultIndex` 建索引并搜索，输出建索引耗时、搜索 p95、堆增量；默认预算 8000ms / 400ms，超预算退出码 1。实测 5000 篇：索引 868ms、搜索 p95 2.4ms、堆增量 24.8MB。

## 新建知识库自带规范

插件的「新建知识库」不再得到空目录：`create()` 会从 `scaffold/vault/` 复刻
**一份笔记编写规范**，但不会预建领域目录和领域 MOC——领域结构由使用者按自己的知识领域创建。

- 只在目录**没有任何 `.md`** 时注入；打开已有库绝不写入文件
- 文件名与正文里的 `{{VAULT_NAME}}` 会替换成新库名，`{{DATE}}` 替换成当天日期
- 文件已存在时以用户文件为准，不覆盖
- 同时复制一份 `.obsidian` 预设：`app.json`（附件目录、链接行为）、`core-plugins.json`、
  `graph.json`（只保留通用显示设置，不含原作者的领域分组配色）、`bookmarks.json`
- 不带 `daily-notes.json` / `templates.json`（日记与模板属于个人工作流），也不带
  `workspace.json`、`community-plugins.json`、`plugins/`（会话状态与第三方插件）
- 规范文件只有：`笔记编写规范.md`、`kb-conventions.md`、`起步说明.md`

更新规范时：修改 `scaffold/vault/知识库总览/笔记编写规范.md`（和 `kb-conventions.md`），
跑 `npm test`（含 `tests/vault-scaffold.test.ts`）。`scaffold/` 会随 npm 包发布。
